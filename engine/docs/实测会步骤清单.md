# 实测会步骤清单（Phase 2：画面建档 + 进游戏闭环）

> 需要你在电脑前配合，全程约 30-60 分钟。开始前确认：
> 1. 游戏显示模式改为 **1920×1080 窗口化**（设置 → 显示 → 显示模式），改完不用重进游戏设置页。
> 2. 关闭标题含"绝区零"的其他窗口（MOD 管理器、浏览器绝区零页等）。
> 3. 引擎目录：`C:\Users\鲁释暄\Desktop\小蕾米引擎`，命令都在这个目录下执行
>    （用 `.venv\Scripts\python.exe`，下文简写 PY）。

## 第一步：验证截图链路（5 分钟，游戏随便停在哪个画面）

```bash
PY -m remi_od.tools capture
```

- 打开 `debug\capture.png`，确认是游戏画面（不是黑屏/不是别的窗口）。
- ⚠️ 如果截到别的窗口内容 → 游戏窗口被挡住了，把游戏点回前台再截。

## 第二步：进游戏画面建档（10-15 分钟）

游戏退到**登录/标题画面**（有"点击进入游戏"字样的那个画面）：

```bash
PY -m remi_od.tools capture
# 对着 capture.png 量"点击进入游戏"按钮的区域（大约在屏幕下 1/4 中间）
PY -m remi_od.tools mark debug\capture.png 782 846 1136 1032   # ← 坐标换量出来的实际值
PY -m remi_od.tools make_template debug\capture.png x1 y1 x2 y2 打开游戏/点击进入游戏
PY -m remi_od.tools match debug\capture.png 打开游戏/点击进入游戏   # 确认命中 score>0.85
```

把 make_template 打印的 YAML 片段贴进 `assets\screen_info\打开游戏.yml`，`id_mark: true`。

**进入游戏到大世界（主界面）后**，再截一张，挑一个稳定不动的 UI 角标（如左上角图标/
右侧任务栏文字）建档为 `大世界` 画面的 `id_mark`。

## 第三步：进游戏闭环实测（10 分钟）

1. 游戏退到标题画面（或直接关掉游戏测自动开游戏）。
2. 启动引擎：`PY -m remi_od.server.main --port 23099`
3. 浏览器访问 `http://127.0.0.1:23099/game/status`，另开一个标签
   `http://127.0.0.1:23099/game/capture` 随时看引擎视角。
4. 触发进入游戏（模拟桌宠）：

```bash
curl -X POST "http://127.0.0.1:23099/game/enter?block=false"
```

5. **双手离开键鼠**，看它自动点"进入游戏"→ 等加载 → 识别大世界后报成功。
   加载要 1-3 分钟，别以为卡住去点游戏。
6. 结果看 `status` 的 `state`：success / failed（`last_status` 有失败原因）。

## 第四步：吼吼饼铺签到建档（15-25 分钟）

在大世界里手动走一遍流程，每个关键画面截一张图并记录：

1. 大世界打开菜单（哪个键/哪里点）→ 截图 → 建档 `菜单`
2. 菜单里进入"更多/吼吼饼铺"入口 → 截图建档
3. 吼吼饼铺交互/领取按钮 → 截图建档
4. 返回大世界的确认/关闭按钮 → 截图建档

每个画面都走"capture → mark 量 → make_template 裁 → 贴 YAML"流程，
然后把 `src\remi_od\apps\daily_signin.py` 里的"画面未建档"占位节点替换成真实的
find_and_click 节点（照 enter_game.py 的写法）。

## 遇到问题

- 引擎日志：控制台直接看（或桌宠的 `绝区零引擎服务.log`）
- 出错截图：`debug\` 目录（异常时自动保存当轮截图）
- 识别不到/点错位 → 大概率是模板裁太大/太花，换更小更独特的区域重裁
